Start here: keep a ::= line as a component
A `::=` line is a quick sum: its expression draws under it. When one earns a name, keep it.

::= (await q("type=seedling")).blocks.length + " seedlings in trays"

- Run `keep name=tray-count` from the power bar on the line above (or `ep0ch act ext.script:keep.run block=<this note> name=tray-count`).
- The line becomes `::tray-count{}`, and its code moves to a child note, **Tray count**, that draws it.
- Write `::tray-count{}` in any other note to draw the same count there; one undo takes the keep back.
