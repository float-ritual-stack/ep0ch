### The parity walk's verdict no longer turns on how busy the box is, and the power bar's ctrl+u names itself (PIE-1814, PIE-1454)

- **Not a chord that lapsed:** the Nov 20 nightly's `X  ctrl+k ctrl+u  ran bar.edit, whose keys don't name it` was true every night. ctrl+k opens the power bar and ctrl+u clears its line; no prefix times out between them (the door's only timed two-key windows are a second ctrl+] within 1.5 s and resize's 4 s idle).
- **The door:** the bar's clear, erase-word and cut (ctrl+u, ctrl+w, ctrl+x, alt+x, cmd+x, or a rebind's) ran `bar.edit`, whose keys named none of them. The line's key table owns those keys, so `bar.edit` now runs as the table's key (`asBoundKey`): the run says which key pressed it, and a rebind names the new one.
- **Why only on a busy night:** the walk checks a second key again on a state built afresh, and clearing an empty line changes nothing, so it let the key go. On a busy box the door's status bar says `slow: N ms to settle` after a minute of slow frames, and its number moves by itself: the night it moved between the walk's two looks, the screen "changed" and the finding stood.
- **The walk, two fixes:** its look leaves the slow chip out, as it does the clock and the uptime (the box's speed is never a key's doing). And a second key that ran the same unnamed actions in the walk, where they changed the screen, and on the fresh build is a finding whether or not the fresh screen changes: `X` goes red on the unfixed door every run, in 55 s, with no load.
- **A busy box on demand:** `PARITY_BUSY_MS=120` draws each probed key's frame that late. `PARITY_ONLY=X` went red on it before the fix (a click blamed for `slow: 158 ms` → `slow: 160 ms`); three busy loops beside the run found nothing in 316 s.
- **PIE-1454** (`^W` then ctrl+k "ended ^W with no action", once, Oct 30): ^W then ctrl+k is a cancel and runs nothing by design; that night's fresh build differed by the daily layout's editor tile, fixed in PIE-1811.
- **Run:** nothing; no PROTOCOL, GRAMMAR or schema change. The budget file is untouched.
