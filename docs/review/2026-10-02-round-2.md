## What changed

**Outliner #271 changes the door needs**
- **`proposal.dismiss` goes through the service** (`draft.proposal.dismiss`, added to the capability list). The service takes the embed line out of the note, or out of the live draft of it, marks the proposal dismissed, trashes it and checks the owner. The door no longer strips the line, trashes the block or decodes the private `[draft-patch::…]` payload: `proposalOwner`, `withoutEmbed`, `holdsDraft` and `currentEmbed` are gone. A `warning` from apply or dismiss is flashed.
- **`[proposal-applies::no]`**: such a proposal draws only `[dismiss]`, on its embed's source line and in an opened proposal's header. The hint names only `X`. `A` and `proposal.apply` refuse and say why.
- **Lens B**: `A` is gated by `currentProposal()`, as `X` is. On an ordinary embed the key isn't taken, so it no longer flashes "isn't a draft proposal".
- **`Draft.applyPatch`** keeps a forced patch above the mark when the draft has the mark line. When the line is missing it lets the patch through, as the service does.
- **Vendored compare v2**: `src/vendor/draft-patch-compare.ts` is a copy of the outliner's. `PINNED_SHA256` is `e38e425a…`, checked with sha256sum and unchanged by 3c34bde.
- **Agent request status `dismissed`** is drawn like the other statuses (`projection.ts`). The drawing code is generic, so only its comment and a test were added.

**F6/F9: "in the Trash" for a note trashed with an ancestor.** There was one rule written three times (desk.ts:671, screens.ts:906, river.ts:1207). It is now one helper, `NoteSurface.staleOn(e)`. It re-reads the note when:
- the event names the note with a revision the reader hasn't seen,
- the event is a reset,
- the event is any delete, restore or purge. These are rare, and the service's event names only the root and moves no revision.

The desk's readers, the river's columns and the BBS message reader all use it. The river column never said "in the Trash" at all. `rootOf` now takes the surface's re-read when only its trash state differs, and the column's banner says it. The wording is one constant, `IN_TRASH`. desk.ts changes only at the re-read site, plus removing the now-unused `trashOrRestore`.

**F2: the "an agent edited text above your cursor" notice outlived the draft.**
- `noteAgent(by, did, draft)` ties the notice to the draft.
- `closeDraft(saved)` clears it when the draft is saved or closed unchanged.
- When the draft is put aside, it becomes "edited the draft you put aside".
- A forced patch that only takes a proposal's embed line out (the service dismissing it from a draft) is now worded as a dismissal, not "applied a proposal". The service names it on the patch (`proposal: { id, op }`, outliner #271), so the door doesn't read the patch's shape.

## Found while reviewing the fixes

Each fix PR had a review pass, architecture first, before it merged. These were found there and fixed
in the same PR.

- **High:**
  - **#273:** the outline host never ran the `@name` start: no baseline seed and no restart sweep. The host
    opens outlines through `startHosted`, which skipped `agentRequests.start()`.
  - **#104:** the board's readers kept their own stale rule, so a board reader never said "in the Trash".
    It now asks `NoteSurface.staleOn`. The same review coalesced re-reads (`NoteSurface.reread`) so a
    burst of trashes can't start a read storm.
  - **#106:** making `ep0ch open` an action routed it to the board's `open`, which gave the opened detail
    the person's keys. An agent's open without a named reader is now quiet.
- **Medium:**
  - **#102:** a refused dock fell back into a shut drawer, putting the keys on a hidden tile.
  - **#102:** `layout.load` by an agent dropped a container lock the person set.
  - **#103:** the reference popup had its own control stripper and code-point cut.
  - **#103:** the editor still wrapped by code points, which hid half a CJK line.
  - **#104:** the door guessed a dismissal from the patch's shape. The service now says which proposal
    operation a patch is.
  - **#105:** an agent's `tile.type` without `reader=` typed into the first terminal it found. It must now
    name the tile when there's more than one.
  - **#105:** the board found its drawers by tile name.
  - **#106:** a second, lighter copy of `agentMayMove` (`agentMayLand`).
  - **#271:** a proposal that reached the mark showed [apply] but could never apply.
  - **#272:** the door saved an `@agent`-only draft as `ext:tidy`, which the reserved namespace now
    refuses. Door #106 records it as the person's, with the extension.
  - **#107:** tracing D2 showed that starting an edit by key (`e C i I ctrl+e` on the board's lanes and the
    desk's reader) ran no action. Fixed in door #108.
