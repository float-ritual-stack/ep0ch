# UI prototypes

[Compact Outliner](compact-outliner.html) explores a smaller menu row, optional expanded chrome, adjacent Preview and inline task/comment interactions. Open the HTML file in a browser; it uses built-in sample content and makes no service requests.

This is a design mockup, not a shipped reader or an implementation commitment. Pane-header integration, responsive components, task controls and comments still need their own service/UI work and acceptance evidence. The live Outliner workboard owns their status.
