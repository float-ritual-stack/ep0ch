# PIE-1267: hand a file to ep0ch from anywhere

What was built and where: the outliner README, "Handing a file over from outside". This page is for the deployer.

## Wire changes

New host actions, answered by the outline host like `loki.lease.*`: `uploads.take`, `uploads.finish`, `devices.add`,
`devices.list`, `devices.revoke`. New outline action `artifacts.lease` (in outline-core's `ArtifactRequest`). New
outline-core types `UploadLease`, `UploadDevice`, `UploadTake`. `PROTOCOL` goes to main's value plus one at the final
rebase. No schema change: leases and device tokens are digests in `<outlines>/.host/upload-tokens.json` (0600).

## To run after merging (float-2)

```sh
ep0ch install --apply
systemctl --user restart outliner-publish outliner-publish-gurgle ep0ch-artifact-watch
```

The publisher serves the new route and the watcher reads the new `inbox-remote/` folder; both keep old code until
restarted (the hub's "Publishers after a deploy").

## Caddy: no change

`my.ep0ch.sh` is a bare `reverse_proxy 127.0.0.1:8795` with no request-body cap, so a 64 MiB upload passes. The route is
`/_upload/<token>` on that block, ahead of the sign-in inside the publisher (the same way `/loki/<token>/` is). The
access log must not record the path: Caddy's default log format would, so if an access log is enabled for
`my.ep0ch.sh`, add

```
	log {
		format filter {
			wrap json
			fields {
				request>uri regexp "^/_upload/[^/?]+" "/_upload/…"
			}
		}
	}
```

(`/loki/<token>/` has the same exposure; this is the same fix.) No access log is configured today.

## Optional: record arrivals in pie

The watcher writes the arrival record in the lease's outline unless told where records go. To keep them in pie:

```
# ~/.config/systemd/user/ep0ch-artifact-watch.service.d/records.conf
[Service]
Environment=EP0CH_ARTIFACT_RECORDS=pie
```

then `systemctl --user daemon-reload && systemctl --user restart ep0ch-artifact-watch`. The watcher must also reach the
host: it uses `<EP0CH_OUTLINES or ~/outlines>/.host/host.sock`, which is where the unit already looks for outlines.

## Checks the deployer can run

```sh
ep0ch artifact lease upload-check --ws pie            # prints a curl; the link is a secret
curl -sS -T ./some-page.html '<link printed above>'   # {"ok":true,"name":"upload-check","version":1,...}
ep0ch device add "Test phone" --ws pie && ep0ch device ls && ep0ch device revoke "Test phone"
```

Remove the test artifact afterwards: `ep0ch artifact rm upload-check` and the card in today's note.
