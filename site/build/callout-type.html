Guide

Add a callout type

Give your outline its own callout, > [!recipe] with its own icon and tone, by writing one note. Use it when the same kind of aside keeps turning up in your notes: recipes, decisions, incidents. Every client draws it, the editor offers it while you type, and the type choice lists it.

kind configuration · a note3 steps, no code, no restartneeds PIE-538

1A type is a note

An outline's callout types are the thirteen built-ins plus every note that has a [callout-type::name] property. Properties on the same note set the type's icon, tone, title and other names.

The outline host answers the list. The door's reader, its completer and its type choice read it, and so does the outliner's Detail, all through one registry in outline-core. Edit the note and every client draws the new type within a second.

2Make one

Try it on an outline of its own first. Make one, and name it in a folder's .ep0ch, so ep0ch run there opens it:

shellbash
ep0ch outline create kitchen-test
mkdir -p ~/kitchen-test && cd ~/kitchen-test
echo 'ws = "kitchen-test"' > .ep0ch

Then ep0ch in that folder opens the door on it. Write each note below as a new note: on the board, press N, paste the text, and press ctrls.

  1. Declare the type: a note named for what it is, with the type's properties.

    note · Recipe calloutsmarkdown
    Recipe callouts [callout-type::recipe] [callout-icon::♨] [callout-tone::green] [callout-aliases::dish]

    the note, with four properties under its title.

  2. Use it in a note, by its name and by its alias.

    note · Sunday soupmarkdown
    Sunday soup [menu::sunday]

> [!recipe] Soup stock
> Bones, an onion, two bay leaves.
> > [!dish]- Leftovers
> > Freeze in jars, two fingers from the top.

    the reader draws ♨ Soup stock straight away.

  3. Draw it the way a reader does.

    shellbash
    ep0ch show $(ep0ch find --ids --query "menu=sunday")

    the drawing at the top of this page: ♨ Soup stock framed in green, ♨ Leftovers inside it.

3Change it

The note is the type, so change the note. Open it in the door (e to edit, ctrls to save) or in Detail, and change its first line. Here the tone moves to amber, the type gets a title for callouts written without one, and a second alias.

note · Recipe calloutsdiff
Recipe callouts [callout-type::recipe] [callout-icon::♨] [callout-tone::green] [callout-aliases::dish]Recipe callouts [callout-type::recipe] [callout-icon::♨] [callout-tone::amber] [callout-title::Recipe] [callout-aliases::dish, meal]
copy gives the + line: the note's new first line

Then a new note that uses the alias meal and no title:

note · Tuesdaymarkdown
Tuesday [menu::tuesday]

> [!meal]
> Soup again.
shellbash
ep0ch show $(ep0ch find --ids --query "menu=tuesday")

top level

[!meal] with no title: drawn as Recipe, in amber.

4Reference

PropertyTakesIf it's missing or wrong
callout-typea name: letters, digits, - and _, up to 32The note declares nothing. A name already declared or taken as an alias is refused.
callout-iconone glyph, one terminal column wideThe built-in's icon, or ●. Emoji and wide characters are refused.
callout-toneblue green violet amber coral neutralThe built-in's tone, or neutral.
callout-titleany wordsThe name in words: my-type is "My Type".
callout-aliasesnames, separated by commasAn alias another type already has is refused; the rest stand.
⚠ One mistake never hides the restwarning

A bad icon or tone falls back, and the type still works. The first note to claim a name or an alias keeps it. callout.list, from an agent or the door's control socket, returns each problem with the note it's in.

Declaring a built-in's name ([callout-type::warning]) restyles that built-in: its title, icon and tone change, and its aliases are added to the built-in's.

Tones

A tone is a colour family, not a colour. Each client maps it to its own palette, so a type looks right in the door's calm and night themes and in Detail.

bluenote, info, todo
greentip, success
violetquestion, example
amberwarning
coralfailure, danger, bug
neutralquote, and any undeclared type
